Review Report

Saveinator Grafana Dashboards

11 dashboards · 68 total panels · 4 datasources (Prometheus + Loki)

21 / 50

The dashboards are functionally comprehensive but use Grafana defaults in every visual category. Strong data coverage undermined by generic presentation.

First Impression

No visual claim 4 / 10

Opening "Saveinator Unified Monitoring" reveals six identical green stat panels. The title says "Saveinator" but the visual language says "out-of-box Grafana." Log-dominant dashboards (User Activity, Error & Reliability) look like debugging terminals.

  • No brand color injection — could be any monitoring setup
  • No thumbnail or description annotations per dashboard
  • Raw log panels dominate — no aggregation, no derived metrics

Hierarchy

Logical grouping, noisy execution 5 / 10

Grid layouts are well-measured in most dashboards (6-column stats + 12×8 timeseries pairs). The exceptions lose the user.

  • User Activity interleaves log panels with timeseries at varying widths — visual noise
  • Error & Reliability — 7 of 11 panels are raw logs. Timeseries act as background
  • No rows or collapsible sections — all panels always visible
  • Inconsistent title naming: "Errors / min" vs "Error Rate" vs "RPC Failures 1h"
  • No cross-dashboard navigation

Color Voice

Default cycler only 2 / 10

Color is the weakest dimension. There is no intentional color system.

  • No custom colors anywhere — all rendered via Grafana's default cycler
  • Platforms colored differently in every dashboard — YouTube is green in one panel, blue in the next
  • No semantic color roles (critical / warning / info)
  • No brand hue — zero visual ownership

Type Voice

Inter is competent but unowned 5 / 10

The typeface (Inter) is fine. The problem is what the type says.

  • Inconsistent panel title structure — different verbs, some with interval, some without
  • Legend formatting varies: "messages/min" vs "active message events" vs "daily message events"
  • No panel descriptions or tooltips — user must guess what a metric means
  • Units hidden in fieldConfig but not surfaced in titles
  • Some titles read as raw engineer shorthand

Interaction Feel

Standard Grafana, zero customization 5 / 10

Expected interactions work (auto-refresh, time picker, hover tooltips). Everything beyond plumbing is missing.

  • No template variables — cannot filter by platform, source, or any dimension
  • No deployment annotations — error spikes have no deploy context
  • No dashboard links — every dashboard is an island
  • All panels hardcoded — no Grafana repeat feature used
  • Log panels are pure text dumps — no aggregation, no pattern detection
  • Mismatched query on "Top Recurring Error Messages" panel — groups by container name, not error pattern

Smell Assessment

Default Grafana dark theme. Default color cycler. No custom CSS. No branding. No template variables. Dashboard titles name data sources, not product questions. Heavy reliance on Loki log dumps as a substitute for derived metrics. These dashboards could monitor any service — they do not look like Saveinator's dashboards.

Top Issues (by impact)

  1. No template variables — Adding $platform, $source, $time_range triples usefulness without adding panels
  2. No color system — Platforms need fixed colors. Severity needs semantic hues
  3. Log panel overuse — 7/11 panels in Error & Reliability are raw logs. Replace with aggregated metrics
  4. No cross-dashboard navigation — Low effort, high impact
  5. Inconsistent title/legend naming — Reads as sloppy even when queries are correct
  6. No annotations — Operators need deploy markers for spike correlation
